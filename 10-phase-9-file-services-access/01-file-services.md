# Phase 9: File Services & Advanced Access Control

**Duration**: Weeks 17-18 | **Key Result**: File services configured, access controls enforced

## Phase Overview

| Item | Details |
|------|---------|
| What | Setup file access policies, archive, retention |
| Duration | 2 weeks |
| Depends | Phase 8 (content migrated) |

## Execution Steps

### Week 17: Access Control
- Configure file permissions per department
- Setup OneDrive policies (sharing restrictions)
- Configure guest access for contractors
- Enable expiring access (periodic refresh)

### Week 18: Retention & Archive
- Configure retention policies (7-year archive)
- Setup automated archival for inactive files
- Configure eDiscovery holds for compliance
- Setup lifecycle management (delete old content)

## Success Checklist

- [ ] Permissions correctly configured
- [ ] Share access working by role
- [ ] Guest access limited + monitored
- [ ] Retention policies active
- [ ] Archive working, files accessible
