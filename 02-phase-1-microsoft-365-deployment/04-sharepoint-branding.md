# Phase 1.4: SharePoint & Team Sites Setup

**Duration**: Days 4-5 | **Key Result**: Team sites created, branded, ready for collaboration

## Site Types to Create

| Site Type | Name | Purpose | Owner |
|-----------|------|---------|-------|
| **Team Site** | IT Department | Internal collaboration | IT Manager |
| **Communication** | Company News | Company broadcasts | Communications |
| **Team Site** | Sales Co-work | Sales team collab | Sales Manager |
| **Team Site** | Finance Records | Finance archive | Finance Manager |

## Execution Steps

### 1. Team Sites (Day 4)

1. Create 1 team site per department (IT, Sales, Finance, HR)
2. Set permissions: Department = Edit, Others = Read
3. Create default libraries: Documents, References, Archive

### 2. Branding (Day 4-5)

1. Add company logo (portal branding)
2. Set brand color scheme (theme)
3. Configure site header: Company name + department site name
4. Setup footer with contact info

### 3. Document Libraries (Day 5)

1. Create: Shared Documents (editable), Templates (read-only), Archive (locked)
2. Set retention: Active docs = 1 year, Archive = 7 years
3. Enable versioning: Keep last 30 versions

### 4. Permissions (Day 5)

1. Configure view-only access for read-only groups
2. Enable members-only collaboration for sensitive sites
3. Setup external sharing: Disabled by default

## Success Checklist

- [ ] 4+ team sites created
- [ ] Sites have company branding applied
- [ ] Document libraries created + tested
- [ ] Users can upload/download docs
- [ ] Site permissions working correctly
- [ ] External sharing set to org-only

## Outputs

- Functional collaboration sites
- File management structure
- Department-based organization
- Branded company presence
