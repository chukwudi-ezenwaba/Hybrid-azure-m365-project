# Phase 2: Advanced Security & Threat Protection

**Duration**: Weeks 3-4 | **Key Result**: Advanced threats blocked, DLP enforced, Defender active

## Phase Overview

| Item | Details |
|------|---------|
| What | Harden M365 security, enable threat protection, enforce DLP |
| Duration | 2 weeks |
| Depends | Phase 1 complete |

## Security Policies Activated

1. **Conditional Access** - MFA for all users, location checks
2. **DLP Enforcement** - Block PII/PCI from external email  
3. **Advanced Defender** - Threat analytics, attack simulation
4. **Email Auth** - SPF/DKIM/DMARC records, BIMI branding
5. **Insider Risk** - User activity monitoring, exfiltration detection

## Execution Steps

### Week 3: DLP & Conditional Access
- Convert DLP policies from audit → enforce
- Create Conditional Access rules (MFA + location)
- Monitor DLP events before full enforcement
- Setup DLP violation alerts

### Week 4: Advanced Threat & Insider Risk
- Enable Attack Simulator in Microsoft Defender
- Setup Insider Risk policies for departing users
- Configure data exfiltration detection
- Run first attack simulation on pilot group

## Success Checklist

- [ ] All users require MFA
- [ ] DLP actively blocking sensitive data
- [ ] Conditional Access policies active
- [ ] Attack simulation completed
- [ ] Insider Risk monitoring active
- [ ] No false positive over-blocking
